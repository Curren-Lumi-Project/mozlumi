The installation is complete

Mozlumi has been added to your input sources. Choose Mozlumi's "Hiragana" in the input menu in the menu bar to start typing.

If Mozlumi is not in the input menu

  1. Open System Settings → Keyboard.
  2. Under Text Input, click "Edit…" next to Input Sources.
  3. Click "+" at the bottom left, choose Japanese, and add Mozlumi.
The first conversion after installing, and the first AI conversion, may take a moment while Mozlumi gets ready. After that, conversion is immediate.

Next

  • To update, choose "Check for Updates..." in the input menu (Mozlumi also checks once a day).
  • See the Mozlumi page on カレンラボ (Japanese) for how to use it.
